### Цель работы

Настроить Git-репозиторий и автоматические проверки перед коммитом, выполнить разведочный анализ данных (EDA) и исследовать калибровку вероятностей на датасете Breast Cancer Wisconsin Diagnostic.

### Структура проекта

| Файл | Назначение |

### Запуск программы

Для выполнения работы необходимы Python 3.12 и Git.

Откройте проект в PyCharm и создайте виртуальное окружение, если оно ещё не создано:

```powershell
py -3.12 -m venv .venv312
```

Установите необходимые библиотеки:

```powershell
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
```

Проверьте целостность исходных данных:

```powershell
.\.venv312\Scripts\python.exe lab1.py verify
```

Запустите анализ:

```powershell
.\.venv312\Scripts\python.exe lab1.py run
```

После выполнения программы результаты сохраняются в папке `reports/LAB1/`.

### Проверка лабораторной работы

Для проверки корректности программы:

```powershell
python -m pytest -q
```

Для проверки файлов перед коммитом:

```powershell
python -m pre_commit install
python -m pre_commit run --all-files
```

Для проверки блокировки ошибочных коммитов:

```powershell
python negative_controls.py
```

Для проверки обнаружения изменения исходных данных:

```powershell
python lab1.py tamper
```

Для проверки повторяемости анализа:

```powershell
python lab1.py reproduce
```

Команды `python` выполняются в активированном виртуальном окружении проекта.

### Результаты анализа

Использован датасет Breast Cancer Wisconsin Diagnostic, содержащий 569 наблюдений и 30 числовых признаков.

В ходе разведочного анализа:

- Проверены типы данных, пропуски и дубликаты.
- Исследовано распределение классов: 357 доброкачественных и 212 злокачественных случаев.
- Найдены кандидаты в выбросы методом межквартильного размаха (IQR).
- Построены графики распределений и корреляций признаков.
- Построена диаграмма калибровки вероятностей для варианта 25.

Для исследования использована логистическая регрессия с последующей сигмоидальной калибровкой вероятностей.

Полученные результаты:

| Метрика | До калибровки | После калибровки |
| --- | ---: | ---: |
| Brier score | 0,021442 | 0,033374 |
| ECE | 0,030777 | 0,054166 |

На данном разбиении данных калибровка не улучшила вероятностные метрики, что показывает необходимость оценивать качество метода на независимой тестовой выборке.
